# EPL Match Outcome Predictor

Predicting English Premier League match outcomes using historical data from 1993 to 2023. Covers exploratory data analysis, SQL, feature engineering, classification, regression, clustering, and time series across 12,026 matches and 31 seasons.

## Dataset

Premier League Matches 1993-2023 by Evan Gower (Kaggle). Columns: Season_End_Year, Wk, Date, Home, HomeGoals, AwayGoals, Away, FTR.

## Structure

- `notebooks/epl_match_predictor.ipynb` - main notebook
- `data/raw/` - raw CSV (not tracked in git)
- `data/processed/` - SQLite database (not tracked in git)
- `sql/` - standalone SQL queries
- `PROPOSAL.md` - project proposal
